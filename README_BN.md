# নিঝুমদ্বীপ নির্বাচন অ্যাপ (প্রাথমিক সংস্করণ)

এটি Flutter-ভিত্তিক Android অ্যাপের একটি প্রাথমিক সোর্স প্রজেক্ট। এতে আছে:
- বাংলাদেশ থেকে নিঝুমদ্বীপ পর্যন্ত অ্যানিমেটেড, ইলাস্ট্রেটিভ ম্যাপ-ইন্ট্রো
- নিঝুমদ্বীপের নির্বাচনী পরিবেশের জন্য দৃশ্য-কার্ড
- ভোটকেন্দ্রের সিমুলেশন সম্পর্কে নোট
- নির্বাচনের পর এলাকার চিত্রের অংশ
- মোঃ নাহিদ উদ্দিন, ৬ নং ওয়ার্ডের মেম্বার পদপ্রার্থীর তথ্যের জন্য প্রোফাইল কার্ড

এখনো বাস্তব ম্যাপের স্যাটেলাইট জুম এবং নিঝুমদ্বীপের রাস্তা/ভোটকেন্দ্রের ভিডিও যোগ করা হয়নি। প্রার্থীর দেওয়া ছবি ও পোস্টার এই সংস্করণে যুক্ত করা হয়েছে। নির্বাচনী প্রতীক আলাদাভাবে যোগ করা হয়নি, কারণ সেটি এখনো চূড়ান্ত নয়।

## শুধু মোবাইল দিয়ে APK বানানোর সহজ পদ্ধতি (GitHub Actions)

1. GitHub-এ একটি নতুন repository তৈরি করুন, যেমন `nijhumdwip-election-app`।
2. ZIP ফাইলটি Extract করে এর ভেতরের সব ফাইল repository-তে আপলোড করুন। `.github/workflows/build-apk.yml` ফাইলটিও আপলোড হওয়া জরুরি।
3. Repository-র **Actions** ট্যাব খুলুন।
4. **Build Android APK** workflow বেছে **Run workflow** চাপুন।
5. Build সফল হলে workflow run খুলে **Artifacts** অংশ থেকে `nijhumdwip-election-apk` ডাউনলোড করুন।
6. ZIP artifact Extract করলে `app-release.apk` পাবেন। Android-এ ইনস্টল করার সময় প্রয়োজন হলে এই ফাইলের জন্য install permission দিন।

## নোট
- এটি একটি starter prototype; production-ready অ্যাপ নয়।
- প্রার্থীর প্রতীক, ছবি, জীবনী, প্রতিশ্রুতি এবং এলাকার তথ্য প্রকাশের আগে যাচাই করুন।
- ভোটের গোপনীয়তা রক্ষা করুন; বাস্তবে কে কাকে ভোট দিয়েছেন এমন দাবি বা দৃশ্য ব্যবহার করবেন না।
- Play Store-এ প্রকাশের আগে অ্যাপের নীতিমালা, গোপনীয়তা নীতি, কনটেন্ট এবং স্থানীয় নির্বাচনী বিধি যাচাই করতে হবে।
